# TODOTOBE

メモとタスクを1画面で扱うウェブアプリ。ビルド不要の素のHTML/CSS/JSで、GitHub Pages から配信します。

## 画面

| 画面 | 中身 |
|---|---|
| プロジェクト | 上が **MEMO**（走り書き・プロジェクトごと）、下が **タスク**。境目はドラッグで比率を変えられる |
| タグ | `#タグ` でプロジェクトをまたいで集める。タスク・MEMO・メモが一緒に出る |
| メモ | 切りだした（または新規の）メモの一覧と編集 |
| アーカイブ | 完了したタスクを完了日ごとに。元に戻す／一括削除 |
| 検索 | タスク・メモ・MEMOを本文から探す |

階層は **プロジェクト ＞ セクション ＞ タスク（＋説明）** の3段だけです。サブプロジェクトもサブタスクもありません。

## タグ

本文に `#タグ` と書くと、そのまま拾われます。タグ用の入力欄はありません。

**先頭4色は「固定枠」**で、順番も色も動きません。

| 枠 | 色 | 既定値 |
|---|---|---|
| 1 | 青 | `#映画` |
| 2 | 橙 | `#ビンセントベガ` |
| 3 | 紫 | `#家族` |
| 4 | 緑 | `#じぶん` |

枠の名前はサイドバーの `⋯` から変えられます。空いている枠は既定値で埋まりますが、**自分で付けた名前は上書きしません**。

枠に入っていないタグは、その下に**五十音順**（漢字は読み）で並び、残りの4色（赤・青緑・紺・灰）から自動で配られます。枠の4色とは重なりません。

MEMO とメモ本文の下に**タグの挿入バー**があります。押すと、いま書いている欄のカーソル位置に `#タグ` が入ります（前後が空白でなければスペースを補います）。タスクの追加・編集中でも同じバーから入ります。

## マーカー

文字を選んで色ボタン、または `⌘B`（黄）。同じ色でもう一度押すと外れ、違う色を押すと塗り替わります。MEMO とメモ本文で使えます。

| 色 | 印 |
|---|---|
| 黄 | `==ここ==` |
| ピンク | `++ここ++` |
| 緑 | `::ここ::` |

**保存されるのはただの文字列**です。印が2文字ずつ増えるだけなので、タグ抽出・検索・同期・書き出しはそのまま動きます。読むとき（タグ表示・メモ一覧・検索）は印を見せず、色だけ出します。

緑はもともと `~~` でしたが、Markdown を解釈する貼り先で打ち消し線になるため `::` に変えました。**古い `~~` は開いたときに自動で `::` へ書き換わります**（`migrateGreenMark`）。`--` は「2026--08」のような文字列と当たるので使っていません。

## 保存の形

`app.js` の冒頭にも書いてありますが、**ここを変えると過去のデータが読めなくなります。**

- タスクは `projectName` / `sectionName` を**文字列で持っています**。IDの参照だけにしていないので、プロジェクトやセクションを消してもアーカイブが読めます
- 完了は `completedAt` を立てるだけです。別の場所へ移していないので、元に戻すのが安全です
- すべての項目が `id` と `updatedAt` を持ちます。端末をまたぐときの突き合わせは**項目単位**です。全体を1つの塊で上書きしないので、iPhone で足したタスクが Mac の保存で消えることがありません

タグの色は `tagColors`（タグ名 → 色）に**1回決めて覚えます**。タグが増えても減っても、既にあるタグの色は変わりません。

## 同期（任意）

初期状態は**この端末の中だけ**（localStorage）です。外へは何も送りません。

設定で同期を入にすると、Firestore が正本になります。

### Firebase 側（設定済み）

| | |
|---|---|
| プロジェクト | `todotobe-62dcd` |
| ロケーション | `asia-northeast1`（**変更不可**） |
| プラン | Spark（無料） |
| Google アナリティクス | 無効 |

ウェブ構成は `app.js` の `DEFAULT_FIREBASE_CONFIG` に埋め込んであります。**この値は秘密ではありません**（クライアントに配られる前提の値で、Firebase の設計上そうなっています）。守っているのは下のルールと同期キーです。

### 端末をつなぐ手順

1. 設定画面を開く
2. 「同期する」にチェック → 「キーを作る」 → 「保存して接続」
3. iPhone 側でも設定画面を開き、**同じキー**を入れて「保存して接続」

構成情報は入力済みなので、2台目以降はキーを入れるだけです。

### セキュリティルール（公開済み）

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /todotobe/{key} {
      allow read, write: if key.size() >= 16;
      match /{document=**} {
        allow read, write: if key.size() >= 16;
      }
    }
  }
}
```

**同期キーはパスワードそのものです。** 知っている人は、あなたのタスクとメモを読み書きできます。他人に渡さないでください。同時に、**失うと取り出せません。** 控えを残してください。

上のルールはキーの長さしか見ていません。より厳しくするなら Firebase Authentication を足すことになりますが、その分ログインの手間が増えます。

## 公開

`main` ブランチのルートをそのまま GitHub Pages で配信します。ビルドはありません。

```bash
cd /Users/ops/Desktop/Code/todotobe && gh repo create todotobe --public --source=. --push
```

そのあと GitHub の Settings → Pages で `main` / `/ (root)` を選びます。公開先は
`https://watanabeops.github.io/todotobe/` です。

**Pages を使うにはリポジトリを公開にする必要があります**（無料プランの制約）。
公開すると `app.js` の Firebase 構成も読めますが、上に書いたとおりこれは秘密ではありません。

## スマホでの見え方

幅720px以下でサイドバーが引き出しになり、左上に**いまいる場所を出すボタン**（`☰ プロジェクト名 ▼`）が出ます。押すと引き出しが開き、もう一度押すと閉じます。表示はプロジェクト・メモ・アーカイブ・検索・設定・タグで変わります。

高さは `100dvh` を使っています。`100vh` は iOS Safari だとブラウザのバーの分だけ画面より大きく、**下端に固定した「同期」が画面外へ落ちます**。

## iPhone に入れる

公開したURLを Safari で開き、共有 →「ホーム画面に追加」。全画面で開き、オフラインでも動きます。

> **ホーム画面から削除すると、その端末に保存された記録も消えることがあります。**
> 同期を入にしておくか、先に設定画面から JSON を書き出しておいてください。

## Service Worker

`sw.js` は**ネットワークを先に見て、失敗したときだけキャッシュを出します**。逆にすると、直したはずの古いファイルが配られ続けます。

## バックアップ

設定画面の「JSONで書き出し」で全データを保存できます。「JSONを読み込む」は**いまのデータをすべて置き換えます**。
